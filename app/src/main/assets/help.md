# Effect Editor 使用说明

## 快速开始
1. 点击"编译"即可运行默认示例特效。
2. 预览区支持双指缩放、单指拖动平移。

## 代码编辑
- 自动语法高亮（Java + Mindustry API）。
- 自动补全：输入 . 或按 Tab 键触发。
- 查找替换：点击顶部"查找"按钮。
- 撤销/重做：顶部 ← → 按钮。
- 格式化：点击"格式"自动整理缩进。

## 行操作（右侧"行"按钮）
- 复制行 / 剪切行 / 删除行 / 清空行 / 粘贴行。
- 可在顶部按"行显"按钮显示/隐藏右侧行工具按钮。

## 编译与导出
- 编译失败时，对应代码行会标红；点击底部红色错误日志可跳转到对应行。
- 导出：生成标准 Java 文件，可直接放入 Mindustry 模组。

## 自定义贴图
把 .png 图片放入：
/storage/emulated/0/Android/data/com.r112007.effecteditor/files/sprites/
编译时会自动加载，代码中通过 Draw.rect("文件名", ...) 使用。
